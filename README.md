# WQR — WhatsApp Quick Responder

The product site for **WQR**, a WhatsApp commerce assistant for African SMEs.
A product of **AI-Suplex Labs**, Harare, Zimbabwe.

- **Live:** https://wqr.co.zw
- **What it is:** a plain static HTML page (`site/index.html` + `site/images/`). No framework, no build step.
- **Deploy:** Netlify — `netlify.toml` publishes `site/` with no build command.

## Layout

- `site/index.html` — the landing page
- `site/images/` — logo and imagery
- `netlify.toml` — publish configuration

## Local preview

    cd site && python3 -m http.server 8000
